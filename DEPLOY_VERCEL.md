# Развёртывание на Vercel

Загрузите в новый проект **содержимое архива целиком**. В корне загрузки должны находиться:

- `index.html`
- `app.js`
- `style.css`
- `vercel.json`
- папки `data`, `assets`, `sources`

Не загружайте внешнюю папку, внутри которой лежит проект: `index.html` должен быть непосредственно в корне деплоя.

Framework Preset: **Other**.
Build Command: оставить пустым.
Output Directory: оставить пустым.

После Deploy откройте корневой адрес проекта без дополнительного пути.
