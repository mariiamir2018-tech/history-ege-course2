# History EGE Course v0.1

Первая версия единой образовательной платформы по истории.

## Что включено
- каркас блоков 1–12;
- блоки 1–6 привязаны к кодификатору ОГЭ 2026;
- блоки 7–12 привязаны к кодификатору ЕГЭ 2026;
- полностью заполненный модуль 9.1 «СССР в 1945–1953 гг.»;
- 15 учебных тем, иллюстрации, причины, последствия, ЕГЭ-акценты и вопросы;
- сохранение прогресса в localStorage;
- поиск, светлая/тёмная тема, адаптивный интерфейс.

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите содержимое папки на Vercel, Netlify или GitHub Pages.

## Источники структуры
В папке `sources` находятся кодификаторы ОГЭ/ЕГЭ 2026 и подробный навигатор ФИПИ по истории России с 1914 г.

## Обновление 9.3
Добавлен модуль «Советское государство и общество в середине 1960-х — начале 1980-х гг.»:
- 15 теоретических блоков по теме кодификатора;
- хронологическая лента, термины, причины, последствия и историческое значение;
- 18 заданий большого проверочного теста с объяснениями;
- иллюстрации, извлечённые из предоставленного учебника истории России для 11 класса;
- изображения показываются без растягивания и разрушительного кадрирования.

Исправление v0.3.1: удалена битая ссылка на отсутствующее изображение Ту-144; блок науки теперь показывает только проверенную иллюстрацию вычислительной техники.


## Версия 0.4 — модуль 9.4
