# History EGE — стандарт модуля

1. Каждый модуль сверяется с кодификатором, Навигатором ФИПИ и учебником.
2. Теория раскрывает причины, ход, итоги и значение.
3. Карта используется только с пояснением «что увидеть».
4. Изображения не растягиваются выше исходного разрешения и не обрезают важные детали.
5. Каждый модуль содержит хронологию, термины, блок ЕГЭ, частые ошибки и тест с объяснениями.
6. Модуль считается готовым только после проверки всех обязательных подтем.
